# XariotReupload

Xariot is a reupload of my dissertation project from 2019. It is a file-synchronization tool that offers real time collaboration on written files in a Client-Server architecture.

**Features:**

-Cross-machine collaboration via client-server architecture.
-Real time synchronization of different files and real time conflict resolution following git's model.
-Encrypted communication via sockets.
-Administration options for the server owner / user management.
-Spring Boot integration for inviting users to a specific project via email.
